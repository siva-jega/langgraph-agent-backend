Agent LangGraph Map

A quick reference for the customer-facing agent graph in this repository.

Request Path

1. FastAPI apppackages/agent/app/main.py
2. Agent routemodules/agents/route.py
3. Agent servicemodules/agents/service.py
4. Graph runnermodules/agents/graph/graph.py
5. Graph nodesmodules/agents/graph/nodes.py

Graph Shape

START
  -> trim
  -> llm
  -> tools, when the last AI message contains tool calls
  -> trim
  -> llm
  -> escalation_check
  -> END

Node Meanings

trim: keeps the message history small before the next LLM call.

llm: builds final messages, binds enabled tools, calls the model, and streams tokens/tool-call events.

tools: uses LangGraph's ToolNode to execute model-requested tools.

escalation_check: checks whether the conversation should be handed to a human before the graph ends.

Key Idea

The graph is a loop. The LLM does not execute tools by itself. It requests tool calls; tools_condition routes to tools; ToolNode runs the tools; then the result goes back to the LLM.
